# XCurveFitLab Playground

Laboratorio web interactivo de ajuste de curvas mediante algoritmos genéticos. Proyecto independiente, inspirado en la experiencia de TensorFlow Playground y basado conceptualmente en [XCurveFitLab](https://github.com/matepraxis/Xcurvefitlab).

> Estado: desarrollo inicial. Los avances se incorporan mediante pull requests y la publicación en Render se realizará cuando la aplicación tenga pruebas suficientes.
